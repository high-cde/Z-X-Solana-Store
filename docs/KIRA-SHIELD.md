# Scudo K.I.R.A. nel Z-X Solana Store

Ogni link esterno (partner, eSIM, annunci) passa dal controllo Scudo K.I.R.A. prima di essere mostrato o cliccato.

## Controlli

- Sosia di dominio ufficiale ZDOS
- Blocklist Phantom / phishing
- RDAP / DNS / HTTPS
- Semaforo rosso/giallo/verde con motivazione

## Implementazione

Nel prototipo è simulato. In produzione si collega al modulo K.I.R.A. o al Security Agent.
